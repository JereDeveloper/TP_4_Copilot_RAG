# Entrega 4

## Propósito

Esta entrega integra el proceso de negocio, el trabajo colaborativo y los mecanismos de control del proyecto Copilot RAG para la atención en Startek Córdoba.

## Contenidos

- Modelado del proceso de atención mediante BPMN.
- Historias de usuario para organizar el trabajo.
- Indicadores para evaluar la propuesta.
- Documentación del trabajo colaborativo en GitHub.

## Estado

El proyecto es una propuesta académica documentada. El software todavía no está implementado y las metas definidas son objetivos, no resultados medidos.
