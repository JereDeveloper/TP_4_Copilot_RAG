# Declaración de uso de inteligencia artificial

## Herramientas utilizadas

En trabajos previos se utilizó Gemini. Para organizar esta documentación y aprender el flujo de GitHub se utilizó ChatGPT/Codex.

## Uso realizado

Las herramientas ayudaron a ordenar consignas, preparar borradores de historias de usuario e indicadores, y revisar la redacción. También se usaron para explicar el uso de GitHub y GitHub Projects paso a paso.

## Revisión humana

La inteligencia artificial se utilizó como apoyo. Antes de entregar, el estudiante debe revisar el contenido, validar las decisiones del proyecto y comprobar que las metas aparezcan como objetivos, no como resultados medidos.

## Protección de datos

No se incluyeron datos reales de clientes, credenciales, audios ni protocolos internos protegidos.
