# Asistente Copilot RAG para Startek Córdoba

Proyecto académico de Organización Empresarial. Propone un asistente que ayuda a los agentes de atención a encontrar protocolos vigentes y preparar sugerencias con sus fuentes.

## Objetivo

Apoyar la atención y la consulta de información, manteniendo la validación final en manos del agente.

## Estado

Este repositorio contiene la documentación y planificación del proyecto. El software todavía no está implementado y las metas definidas son objetivos, no resultados medidos.
